# Lotto Max 历史结果分析与号码生成工具

该项目包含了一套用于分析 Lotto Max 历史开奖结果并根据历史规律生成推荐号码的工具脚本。

## 目录结构

- `pastresult.txt`: 存放 Lotto Max 历史开奖结果的数据文件（已更新至 2026年10月9日）。
- `fetch_history.py`: 从 getmylottoresults.com 抓取全部历史结果，补进 `pastresult.txt`（只增不删，按日期倒序）。
- `analyze_lottery.py`: 深度分析脚本，用于统计奇偶分布、和值趋势、连号规律、热门号码及组合。
- `generate_numbers.py`: 号码生成脚本，基于历史规律并结合历史查重功能生成推荐组合。
- `record.txt`: 相关参考链接记录。

## 核心规律分析

根据对 1100+ 期历史数据的分析，Lotto Max 的中奖号码呈现以下显著规律：

1.  **奇偶分布**: 约 **58%** 的开奖结果奇偶比为 **4:3** 或 **3:4**。
2.  **连号规律**: 超过 **60%** 的开奖号码包含连号，其中 **41.32%** 的期数正好包含 **1 组连号**。
3.  **平均和值**: 7 个常规号码的平均总和约为 **175**。
4.  **号段分布**: 号码范围 1-52，在 1-10, 11-20, 21-30, 31-40, 41-52 五个区间分布相对均匀，平均每个区间落号 1.4 个。

## 使用方法

### 0. 更新开奖数据
```bash
pip install -r requirements.txt
python3 fetch_history.py
```

### 1. 运行深度分析
查看最新的统计数据和规律总结：
```bash
python3 analyze_lottery.py
```

### 2. 生成推荐号码
根据历史高频规律（奇偶平衡、单组连号、和值区间、历史去重）生成推荐组合：
```bash
python3 generate_numbers.py
```

## 生成器筛选条件
`generate_numbers.py` 脚本会自动筛选符合以下条件的号码：
- 奇偶比仅限 4:3 或 3:4。
- 必须且仅包含 1 组连号。
- 号码总和控制在 160 - 190 之间。
- 断区（无号段）不超过 1 个。
- **自动比对 `pastresult.txt`，确保生成的组合在历史上从未出现过。**
